# Idiomas de la interfaz (#72)

TurboSpice es **nativa en inglés**; el español es una traducción.

- Todo texto que ve el usuario se escribe **en inglés** y pasa por `t()` (`src/i18n/i18n.ts`):

  ```ts
  import { t } from '../i18n/i18n.ts';
  setMessage(t('Saved to Google Drive: {name}', { name }));
  ```

  La clave es el propio texto en inglés. `{nombre}` se reemplaza por el parámetro del mismo nombre;
  una llave sin parámetro (`{R}` en un ejemplo de valor) queda como está.
- Su traducción va en **`src/i18n/es.ts`** (inglés → español), con los mismos `{parámetros}`.
  Si falta, con el idioma en español se ve el inglés: nunca vacío.
- No uses una variable local llamada `t` en un archivo que importa `t()` (la tapa).
- Plurales: un texto por caso (`'1 simulation'` / `'{n} simulations'`), no sufijos sueltos.
- Lo que no se traduce: comentarios del código, lo que escribe el usuario (nombres, textos del
  esquemático, ejemplos `.asc`), la salida cruda de ngspice y los comentarios de netlist que se usan
  como marcadores (`directives.ts`).

## Cambiar de idioma

El botón **EN ES** de la barra superior (al lado del tema). El idioma se guarda en
`localStorage` (`turbospice.lang`); por defecto es inglés, sin mirar el idioma del navegador.

El idioma se fija al cargar la página (hay textos armados a nivel de módulo y los bloques de
Blockly se definen una sola vez), así que cambiarlo guarda el proyecto entero —con lo que se está
editando— y recarga: el autoguardado lo trae de vuelta con sus resultados. Lo que se pierde es la
pila de deshacer, como en cualquier recarga.

## Control

```sh
node scripts/i18n/check.mjs
```

Lista los textos en español que quedaron fuera de `es.ts` (sale con error si hay) y las claves de
`t()` sin traducción. `tests/unit/i18n.test.ts` verifica que cada traducción tenga los mismos
parámetros que su texto en inglés.

## Tests

Los unitarios corren con la interfaz en español (`tests/setup-i18n.ts`): sus mensajes esperados
están en español. Los e2e también (`spanishUi` / `skipWelcome` en `tests/e2e/lib.mjs`).

## Cómo se hizo la conversión

`scripts/i18n/scan.mjs` (inventario), `codemod.mjs` (reemplazo por `t()` y generación de `es.ts`)
y `rename-t.mjs` (variables locales `t` → `tt`) se usaron una vez para pasar el código a inglés;
quedan como referencia.
