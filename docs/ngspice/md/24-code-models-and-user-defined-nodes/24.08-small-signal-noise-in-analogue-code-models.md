## 24.8 Small signal noise in analogue code models

The simulation of small signal noise (see 11.3.4) may be enabled in analogue code models.
It is implemented by MIFnoise(), the generic noise callback for all XSPICE code models.
Two discovery modes are supported: declarative, where models define reserved parameter
names (noise_voltage, noise_current, noise_corner, noise_exponent) and get automatic
noise sources and programmatic, where models register sources via cm_noise_add_source()
during MIF_NOI analysis calls.

Declarative: Models that define reserved parameter names (noise_voltage, noise_current,
     noise_corner, noise_exponent) get automatic noise sources bound to their first out-
     put or input port.

Programmatic: Models that set noise_programmatic=TRUE have their cm_func called with
     MIF_NOI, allowing them to register arbitrary noise sources via cm_noise_add_source()
     and set densities via NOISE_DENSITY().

Please see the OTA provided in \src\xspice\icm\analog\ota\cfunc.mod as an example
for the programmatic approach, and the simple gain cell where only the (then user selectable)
parameters noise_voltage, noise_current, noise_corner, noise_exponent have been
added to \src\xspice\icm\analog\gain\ifspec.ifs.as an example for the declarative approach.
