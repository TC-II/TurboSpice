# Botón "Iniciar sesión con Google"

`signin-light.svg` y `signin-dark.svg` son los botones oficiales de sólo ícono (forma
redonda) del paquete `signin-assets.zip` de las guías de marca de Google
(https://developers.google.com/identity/branding-guidelines), copiados sin cambios:

- `Android + Web/SVG/Light/Theme=Light, Show text=No, Shape=Pill, Platform=Android+Web.svg`
- `Android + Web/SVG/Dark/Theme=Dark, Show text=No, Shape=Pill, Platform=Android+Web.svg`

No editarlos ni recolorearlos: las guías sólo permiten escalarlos. Para actualizarlos,
bajar de nuevo el paquete oficial y reemplazar los archivos.
